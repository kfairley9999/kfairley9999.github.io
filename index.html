catchpr

A Provefirst project — a PR comment only when a test proves the change

A GitHub pull-request reviewer that comments only when a generated pytest passes on the base commit and fails on the head, every time it is run, and a one-line command reproduces that result. If it cannot prove a behavior change, it stays silent. Candidates must pass on base 3/3 and fail on head 3/3; flaky tests are dropped, and deterministic assessors filter false positives. A live replay playground walks through recorded cases.

A Provefirst project — an AI front desk for a small service business

A Model Context Protocol server that lets Claude, Cursor, or any MCP client run a shop’s lead pipeline: 11 tools, 3 resources, and 2 prompts to capture leads, score them with a published rubric, log conversations, schedule follow-ups, and report on the pipeline. ForgePulse

PR triage, CI routing, and portable policy for agentic dev orgs

A small HTTP service that sits next to GitHub: it scores noisy or AI-generated pull requests, records CI failover routing, computes downstream blast radius, searches code and owners, and evaluates portable YAML policy. Version 0.2.0 stores isolated guest workspaces in Cloudflare D1, so state survives restarts. A visitor can try the sample org immediately, or connect their own repository with a webhook and an optional fine-grained PAT so changed files can be fetched. Mutating routes require auth and are rate-limited. 59 tests, 92% coverage. It is not a GitHub App yet, and RunnerMesh records routing decisions only — it does not launch runners.

mcp-doctor

Lint, convert, and handshake-test MCP client configs

MCP configs fail quietly: a missing -y, a url where the client reads serverUrl, or an npx that a GUI cannot see on PATH looks like a client bug and is usually the config. mcp-doctor checks the file against the client that will load it (Claude, Cursor, VS Code, Windsurf, Codex, Gemini CLI, Zed, and more), rewrites it for the client you actually use, and opens a real initialize handshake so you can see the failure. The live playground checks a paste in the request and then drops it.

mcp-sync

A synchronous client for the official MCP Python SDK

Use MCP from Celery, Django, a script, or a Jupyter kernel. One SyncClient owns a background event-loop thread so the session survives from call to call — unlike wrapping the async SDK in asyncio.run, which opens a new connection every time and raises inside a running loop. Built on the public mcp.Client, not a second protocol implementation. A recorded demo is in the repository.

Communications API

Relaycomm

Self-hosted, Twilio-compatible programmable SMS and Voice API

A FastAPI control plane that mirrors Twilio's REST shape: Messages and Calls under /2010-04-01/Accounts/{Sid}, Account SID plus auth token basic auth, SM… / CA… / RE… SIDs, and status callbacks signed with an X-Twilio-Signature-compatible HMAC. A TwiML interpreter runs <Say>, <Play>, <Gather>, <Dial>, <Record>, and <Hangup> against an offline simulator. Pluggable adapters cover SMTP email-to-SMS, a documented Asterisk/FreeSWITCH SIP stub, and optional Telnyx/Vonage passthrough. SQLite storage, a local web console, Docker Compose, and 12 passing pytest tests. It does not deliver to the public telephone network unless you attach a carrier or SIP trunk; that path is not configured.

About me
